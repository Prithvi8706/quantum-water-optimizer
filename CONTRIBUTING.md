# Contributing

Thanks for your interest in improving the Quantum Water Optimizer!

## Getting started

1. Fork and clone the repository.
2. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate   # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Run the project:
   ```bash
   python main.py
   ```

## Making changes

- Create a feature branch off `main` (e.g. `feature/your-change`).
- Keep changes focused and surgical — touch only what you need to.
- Match the existing code style.
- Test your changes locally before opening a pull request.

## Submitting a pull request

- Describe what the change does and why.
- Reference any related issues.
- Make sure the project still runs after your change.

## Reporting issues

Open an issue with a clear description, steps to reproduce, and your environment
details (OS, Python version).
